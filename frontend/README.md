# EZER Frontend Module

This directory contains the user-facing React web application for EZER Learning Solutions.

## Architecture

```
frontend/
├── src/                # Component views, pages, and context managers
│   ├── Admin_Control/  # Dynamic Admin control dashboard components
│   ├── components/     # Reusable UI cards, banners, header, footer
│   ├── pages/          # Public page views (Home, Courses, CourseDetail, About, etc.)
│   ├── services/       # Firebase & client-side database integrations
│   └── utils/          # Image, video, and layout utilities
├── public/             # Static public assets, icons, logos
├── index.html          # HTML entry point with WebMCP & SEO metadata
└── README.md
```
