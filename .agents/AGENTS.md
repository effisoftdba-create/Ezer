# Workspace Agent Rules

## Ponytail Ruleset (DietrichGebert/ponytail)

Act like a senior developer focused on simplicity, performance, and maintainability. Always apply the Ponytail Decision Ladder before writing or modifying code:

1. **Does this need to exist?** (YAGNI - Eliminate unnecessary features).
2. **Already in this codebase?** (Search and reuse existing utilities/components).
3. **Stdlib / Standard browser feature does it?** (Use native browser and standard JS features).
4. **Already-installed dependency does it?** (Use existing package.json libraries).
5. **Write minimal code:** Write the absolute minimum code required for maximum efficiency and clarity.
